# Clinical Trial Mentor（临床试验带教导师）· 公开版

基于 2026 版 GCP 法规与 200 道自编题库构建的带教式临床试验专家（WorkBuddy 专家包）。
答疑与日常学习一体：像带教前辈一样回答执行问题，内置三种学习模式。

> 内置资料：2026 版 GCP 法规全文、临床试验全流程操作指南三部曲（process-1/2/3，
> 前期准备 / 中期执行 / 数据与收尾）、200 道题库。`references/` 仍可继续放入你的自有资料（见下文"扩展知识库"）。

## 功能

1. **实操答疑**：临床试验执行全流程问题，结论先行、必附踩坑提醒与资料出处。
2. **GCP 法规解读**：2026 版 GCP 条款查证与"人话"翻译。
3. **三种学习模式**：
   - 考我模式：说"考我"，情景题作答 + 逐条点评
   - 今日一招：说"今日一招"，一个踩坑场景的情景小故事
   - 专题串讲：说"串讲 XX"，把相关内容串成一次完整讲解 + 自测 3 题

## 使用示例

- "考我，来3道伦理相关的题"
- "今日一招，讲一个容易踩坑的场景"
- "知情同意全过程有哪些容易踩的坑？"

## 扩展知识库（可选）

内置资料已包含 GCP 法规、全流程三部曲（process-1/2/3.md）与题库。如需继续扩展，把你的资料（Markdown 格式）放入：

```
skills/clinical-trial-kb/references/
├── process-1.md   # 前期准备类（立项、伦理递交、合同、中心启动）
├── process-2.md   # 中期执行类（招募、知情同意、药物管理、AE/SAE、监查）
└── process-3.md   # 后期收尾类（数据清理、锁定、CSR、中心关闭、注册申报）
```

放入后无需改任何配置，专家会自动按标题层级检索引用。资料请用 Markdown 标题组织章节。

## 安装（WorkBuddy）

方式一：WorkBuddy「专家」入口 → 我的专家 → 导入本目录（或 zip 包）。
方式二：将整个 `clinical-trial-mentor/` 目录放到专家目录：
`~/.workbuddy/plugins/marketplaces/my-experts/plugins/`，重启 WorkBuddy 后在专家中心即可见。
