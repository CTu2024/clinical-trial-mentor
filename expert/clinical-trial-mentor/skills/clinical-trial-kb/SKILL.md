# 临床试验知识库检索指南

知识库位于本技能的 `references/` 目录。**回答专业问题前必须先检索原文，禁止凭记忆作答。**

## 文件总览

| 文件 | 内容 | 什么时候查 |
|---|---|---|
| `gcp-2026-regulation.md` | 2026 版 GCP 法规完整正文（6 章 54 条，2026-09-01 施行，公开政府文件） | 问法规条款、合规底线、责任归属时 |
| `quiz-bank.md` | 200 道题库（综合卷 100 + GCP 卷 100，含答案要点、踩坑提醒、出处） | 考我 / 今日一招 / 专题串讲模式，以及需要现成考点时 |
| `process-1.md`（可选） | 用户自备：全流程·前期准备类资料 | 若存在，问试验启动前工作时查 |
| `process-2.md`（可选） | 用户自备：全流程·中期执行类资料 | 若存在，问试验执行中的工作时查 |
| `process-3.md`（可选） | 用户自备：全流程·后期收尾类资料 | 若存在，问数据统计后的工作时查 |
| 其他用户自备 MD（可选） | 用户放入的任意培训资料 | 按文件名和内容判断 |

## 主题路由表

**法规（gcp-2026-regulation.md，必查）**
- 按条款号查：Grep "第X条"（如 `第二十六条`）
- 按主题查：知情同意、伦理审查委员会、试验用药品、安全性报告、数据治理、监查稽查……各章直接对应

**题库（quiz-bank.md，必查）**
- 按卷：`综合卷第N题` / `GCP卷第N题`
- 按阶段：每题标题含【阶段 · 题型】，如【伦理与知情 · 情景】

**用户自备资料（若存在）**
- 先 Grep 关键词定位文件与小节，再读完整小节
- 自备资料的引用标注来源为文件名 + 章节标题

## 如何扩展自己的知识库

把你的培训资料（Markdown 格式）放入 `skills/clinical-trial-kb/references/` 目录即可，建议命名：

- `process-1.md` — 前期准备类（立项、伦理递交、合同、中心启动）
- `process-2.md` — 中期执行类（招募、知情同意、药物管理、AE/SAE、监查）
- `process-3.md` — 后期收尾类（数据清理、锁定、CSR、中心关闭、注册申报）

放入后无需修改本文件——路由表已预留这些位置。资料请使用 Markdown 标题（`#`/`##`/`###`）组织章节，便于按标题切分检索。

## 检索方法

1. 按上表定位文件；不确定归属时，先在多个文件 Grep 关键词比较命中密度。
2. 用 Grep 带上下文（如 `-C 3`）搜关键词，再用行号范围 Read 相关小节全文。
3. 关键词选择：优先行业术语（"知情同意"、"超温"、"SUSAR"、"稽查轨迹"），不是日常口语（"出事了怎么办"）。
4. 找到相关内容后，**读完整小节再回答**，不要只看 Grep 命中的单行。
5. 每次回答附出处；找不到相关内容时如实告知"知识库未覆盖"。
