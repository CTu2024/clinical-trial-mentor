# 这套系统是怎么做出来的（制作教程）

记录从"一堆内部培训资料"到"在线题库 + AI 带教导师"的完整路径。照着做，你可以把自己的任何专业领域资料做成同款。

## 总体思路

```
原始资料 → 清洗 → 切片知识库 → 出题（题库） → 学习工具（三种形态）
                                   ↓
                        静态网页刷题 / BYOK AI 导师 / WorkBuddy 专家
```

核心原则：**资料和"方法"分离**。知识库原文不必公开，公开的是题库、人设、检索逻辑——别人导入后放入自己的资料即可复现完整体验。

## Step 1：资料清洗

图片型 PDF 先 OCR 成 Markdown（错别字难免）。清洗的关键是**系统性错字规律**而非逐个校对：

- 用脚本统计高频可疑词（如 OCR 把「盲」认成 9 种错字、`%` 认成 `96`）
- 写正则批量替换，输出清洗报告
- 结构修复：标题层级丢失、编号错乱、乱码表格行过滤

工具：任何脚本语言都行（Python 常用），关键产出是"可复现的清洗脚本 + 清洗报告"。

## Step 2：切片知识库

按标题层级把长文档切成 150-1000 字符的知识片段（一个小节/场景 = 一片），每片带来源字段（"章 / 节 / 小节"）。切片粒度直接决定检索质量：太碎缺上下文，太粗检索不准。

格式示例（JSON）：

```json
{"id": 1, "text": "切片正文…", "source": "文件名", "section": "第9章/知情同意/ICF签署"}
```

## Step 3：出题

让 AI 通读全部切片后命题，要求：

- **情景题为主**（"某申办者做了 X，哪里违规？"），不要光背条款
- 每题带：答案要点、踩坑提醒、来源切片
- 约束来源范围（比如"GCP 卷只准引用法规"），并用脚本程序化校验每道题的 `src` 字段

产出两份资产：交互式 HTML 答题页（纯静态、localStorage 存进度）+ Markdown 题库。

## Step 4：三种学习形态

### 4a. 静态刷题页

一个自包含 HTML：题目数组 + 板块筛选 + 自评按钮 + 进度条。零依赖、可双击打开、可部署到 GitHub Pages。**写完必须做语法检查**（把 `<script>` 抽出来 `node --check`），一次手滑的引号就会让整页白屏。

### 4b. BYOK 网页版 AI 导师（本项目 web-mentor/）

单文件 HTML，无后端。四块积木：

1. **内嵌知识**：法规全文 + 题库以 JS 字面量内嵌（`JSON.stringify` 后注入）
2. **前端 BM25 检索**：中文用字符 2-gram 分词，检索时**配额混合**（法规 top3 + 题库/自备资料 top3），保证回答既有条款依据又有实战要点
3. **BYOK 设置**：用户填自己的 API 地址/Key/模型（Kimi、DeepSeek、OpenAI 兼容均可），存 localStorage，请求从浏览器直连 AI 服务
4. **带教人格提示词**：结论先行、必带踩坑、启发式分层、引用出处、不编造

隐私设计：用户拖入的资料用 FileReader 本地解析建索引，永不上传；只有检索命中的片段随问题发给 AI。

### 4c. WorkBuddy 专家包

专家包 = 人设（Agent MD）+ 检索指南（SKILL.md + references/）。公开版策略：

- `references/` 只放公开内容（法规 + 题库），并为用户自有资料**预留标准文件名**（process-1/2/3.md），路由表提前写好这些位置——放入即生效，无需改配置
- 人设和检索逻辑完整分享，内部资料原文不进包

## Step 5：发布

- 静态部分推 GitHub → Settings → Pages → 得到公开链接
- 专家包打 zip 放仓库，附导入说明

## 踩过的坑

1. **手写 JS 数组里的中文引号**：`pit:\"xx\"是坑` 这种缺外层引号的写法会让整个脚本静默崩溃（页面只剩框架）。写完必须 `node --check` + 浏览器实测渲染。
2. **检索结果被题库刷屏**：题库片段关键词密度远高于法规原文，纯 BM25 的 top6 会全是题。按来源做配额混合（法规保底 3 条）解决。
3. **绝对路径链接**：`/quiz.html` 在 GitHub Pages 子路径下会 404，发布前统一改相对路径。
4. **内部资料版权**：分享"方法"和"人设"，不分享"数据"；给自有资料留标准空位，体验不缩水。

## 传播到其他领域

这套模式适用于任何"有资料、要带教"的场景：合规、质控、销售话术、运维手册……核心就三件事：**资料切片 → 带答案的情景题库 → 带检索的 BYOK 导师**。
