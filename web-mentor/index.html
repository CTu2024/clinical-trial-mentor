设置 AI 服务

① 还没有 Key？点一家去申请（手机号注册，约 1 分钟，新用户有免费额度）

Kimi（推荐·已验证可用） DeepSeek 硅基流动 通义千问 智谱 GLM

在申请页面点「新建 API Key / 创建密钥」，复制 sk- 开头那一整串。已经有 Key 就直接看第 ②③ 步。

② 把 Key 粘贴到这里（首尾空格会自动清理）

③ 点一下，自动认领

不用选服务商、不用填地址和模型名——点上面的按钮，程序会自己判断这把 Key 属于哪家、并用哪款模型。

识别不出来？点这里手动指定（高级）

地址写到 /v1 为止（智谱写到 /api/paas/v4）。粘贴了完整 /chat/completions 结尾、或误填了 platform 官网地址，程序会自动纠正。企业内部网关、Azure OpenAI 等填自定义地址即可，但要求对方允许网页直连（CORS）。
