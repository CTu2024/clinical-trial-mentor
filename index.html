下载专家包（zip）
怎么装到 WorkBuddy？（约 2 分钟）
  1. 点上面的按钮，下载 clinical-trial-mentor.zip（不用解压）
  2. 打开 WorkBuddy → 左侧「专家」→ 我的专家 → 导入，选中这个 zip

AI 实时答疑 · 网页版

备选 · 需要自己的 API Key

不用装 WorkBuddy，浏览器直接用。内置 GCP 法规全文 + 全流程三部曲 + 200 道题，资料齐全；但需要自己申请一个 API Key（Kimi 或 DeepSeek，新用户有免费额度）。

适合：没有 WorkBuddy、但愿意花 5 分钟配一次 Key 的用户。

进入网页版 AI 导师
第一次用网页版？3 步设置（约 2 分钟，只需粘一次 Key）
  1. 进入 AI 导师 → 右上角「⚙ 设置 AI」→ 点卡片里的按钮去申请一把 Key（Kimi / DeepSeek 等，手机号注册，新用户有免费额度）
  2. 把 sk- 开头的一整串粘贴进去
  3. 点「自动识别并保存」——程序自己判断是哪家、自动选好模型，不用填地址和模型名

答题进度和 API Key 只保存在你自己的设备浏览器里；刷题部分离线也能用。
